# Resolution Audit Content Writer Skill

Use this skill to draft content for The Resolution Audit.

## Core Offer

The Resolution Audit turns repeated support questions into a source-backed
action queue.

The target report-shape pattern:

- ranked repeated issues
- estimated cost exposure
- resolution evidence when tickets support it
- customer wording from ticket language
- content output when evidence supports a draft
- no proven answer when evidence is missing
- probable owner lane for the person or department that may need to review the
  cause, when the current report output supports that field
- next review action

## Before/Now Frame

Use this when explaining the pivot:

Before: ranked repeat list, cost exposure, drafted FAQs or answers, customer
wording, and unresolved/no-proven-answer gaps.

Target: all of that, plus probable owner routing for the person or department
that may need to review the root cause when the report output supports it.

## Content Rules

- open with a concrete support-queue observation
- explain the mechanism before the opinion
- preserve owner routing only as target-pattern or data-supported language
- treat no proven answer as useful evidence
- qualify cost as estimated exposure
- qualify ownership as probable or investigatory
- invite a useful reply or next action

## Useful Angles

- Ownership question: who needs to review the root cause?
- Resolved is not fixed: a closed ticket can hide repeat demand.
- Diagnostic, not dashboard: the report tells the operator what to do next.
- Stop turning every repeat into an FAQ.
- Pattern or finding: repeats often point outside support.

## Channel Defaults

- LinkedIn: 120-220 words, short paragraphs, low-pressure question.
- Reddit: useful analysis first, promotion light or absent.
- Reply or DM: answer the person first; explain public context is only a
  hypothesis.
- Blog: define the category; explain proof, mechanism, and action.

## Return Shape

Unless the user asks otherwise, return one draft, three alternate hooks, and
claim-risk notes.
