# Resolution Audit Open WebUI Skills

Paste these files into Open WebUI Workspace Skills.

Install in Open WebUI: Workspace -> Skills -> Create. Paste one file per skill,
then attach it to your model or call it in chat with `$skill-name`.

| File | Suggested name | Use when |
|---|---|---|
| `claim-guard.md` | `resolution-audit-claim-guard` | Claims, cost, privacy, ownership, AI, or outcomes |
| `content-writer.md` | `resolution-audit-content-writer` | LinkedIn, Reddit, replies, blogs, or marketing copy |
| `plain-talk-rewriter.md` | `resolution-audit-plain-talk` | A draft sounds corporate or robotic |
| `report-shape-router.md` | `resolution-audit-report-shape` | Explaining report shape or owner lanes |
| `verifier-reviewer.md` | `resolution-audit-verifier` | Checking a draft before posting |
